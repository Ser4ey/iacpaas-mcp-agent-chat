## Реальная проверка полного приложения

Два запроса выполнены через HTTP API веб-чата, настоящий MCP-сервер и локальный индекс данных IACPaaS. Использована реальная модель RouterAI, без подмены ответов.

1. Вопрос об элементе-основе сплава `12Х18Н10Т`. Модель запросила список ресурсов, дважды использовала поиск и прочитала подграф. Ответ: железо, Fe. Источник указан в ответе: «Справочник по материалам», узел «Основа» 381405980786792 и «Fe» 381405980798350.
2. Поиск точного названия `несуществующийсплав987654` в том же диалоге. Поиск вернул ноль совпадений; приложение сообщило об отсутствии/недостаточности сведений без подстановки характеристик другого материала.

За два пользовательских запроса провайдер учёл шесть обращений к модели: 43 283 входных и 517 выходных токенов, всего 43 800. Все промежуточные обращения включены в счётчик; usage получен от провайдера. Это суммарный расход проверки, а не размер одного промпта.

В браузере проверены сохранённые ответы, журнал инструментов, счётчики каждого ответа и сессии, выбранная модель. История проверки оставлена в приложении в диалоге «Проверка RouterAI…».

Дополнительно проверены новый вход в IACPaaS и экспорт корневой вершины «Базы свойств материалов»: источник данных доступен. Эта проверка не заменяет сохранённый поисковый индекс.
