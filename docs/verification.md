# Проверка 20 октября 2026: агент на LangChain

Самописный цикл агента заменён на `create_agent` из LangChain 1.4 (LangGraph 1.2), MCP-клиент — на `langchain-mcp-adapters` 0.3.2, клиент модели — на `ChatOpenAI` из `langchain-openai` 1.7 с подклассом под поля RouterAI. Модель, API и данные те же, что 19 октября. Проверка шла на отдельном экземпляре (порты 8010/8011) с отдельной базой диалогов.

## Автоматические проверки

`pytest`: 67 тестов, все проходят. Тесты агента работают на настоящем графе LangChain и настоящем `ChatOpenAI`; подменены только HTTP-транспорт модели и инструменты. Добавлены проверки:

- тело запроса к RouterAI: `max_tokens` (а не `max_completion_tokens`), `stream_options.include_usage`, `tool_choice` по шагам;
- `usage.cost` провайдера и фрагменты `reasoning_details` сохраняются и уходят модели в исходном виде;
- запрос инструментов на финальном шаге не выполняется;
- история прошлых ходов доходит до модели с парами «вызов → ответ»;
- остановка пользователем посреди ответа (отмена задачи): частичный текст, расход и корректная история сохраняются;
- переполнение контекста у провайдера (`ContextOverflowError`) показывается своим текстом.

Сквозной тест «HTTP → агент → настоящий MCP-сервер → индекс» проходит без изменений.

## Реальный диалог

| Вопрос | Инструменты | Результат |
|---|---|---|
| «Привет!» | нет | Рассказал, с чем помогает, предложил примеры; 0,07 ₽ |
| «Какой химический состав у стали 12Х18Н10Т?» | `search_graph` + 8 × `get_subgraph` с платформы, часть параллельно | Полный состав: Fe основа 66,7–70,0 %, Cr 17–19, Ni 9–11, Ti расчётное 5·C…0,8 и др. Источник — вершина 381405980786784. 8 обращений к модели, 69 тыс. токенов, 0,88 ₽ |

История с вызовами инструментов принята провайдером на следующем ходе. RouterAI для этой модели не присылает `reasoning_details` (их нет и в диалогах, сохранённых прежней версией), поэтому их поддержка проверена тестом. Стоимость — фактическая из `usage.cost`.

Модель сама выбирает, сколько вершин дочитать. На вопрос о составе вышло 9 вызовов против 6 накануне; это число меняется от прогона к прогону.

Модель прочитала 16 вершин и упёрлась в лимит вызовов; ещё два вызова получили `tool_limit`, и финальный шаг без инструментов сработал как задумано (1,16 ₽). После этого в промпт добавлено правило: при `served_from: local_index_fallback` сказать о снимке и назвать его дату. Повторный прогон — в таблице.

Итого за прогон сценариев — 4,68 ₽.

### Окружение и Docker

- **`.venv` пересобрано.** Прежнее было создано от Python из служебного кэша Codex. Новое создано от Python 3.12.13, установленного через uv (по ссылке `cpython-3.12`, которая переживает обновление патч-версии). Пакеты поставлены из `requirements-lock.txt`, и список установленных версий совпадает с ним полностью. 67 тестов проходят.
- **Docker.** `Dockerfile` теперь ставит зависимости из `requirements-lock.txt` отдельным слоем, а сам проект — без зависимостей. `docker compose build` прошёл; первая сборка заняла около 11 минут, почти всё время ушло на загрузку базового образа и пакетов. Образ весит 394 МБ. После `docker compose up` контейнер ответил на `/api/status`: ключ и модель настроены, индекс готов (94 569 вершин из смонтированной папки `data`), каталог RouterAI загружен (рубли, окно 1 048 576). Отдаются главная страница и статика.
- **Вопрос через контейнер:** «Покажи метаданные базы химических элементов прямо с платформы…». Агент сделал `list_inforesources`, `search_graph`, `count_graph` и `get_inforesource` с живым чтением с IACPaaS (вход по учётным данным из `.env`). Ответ: 153 вершины, 152 дуги, изменена 18.10.2026 20:56:34; 3 обращения к модели, 0,26 ₽. Тестовый диалог после проверки удалён из истории.

### Замечания

- **Модель дочитывает компоненты по одному.** На вопрос о составе без платформы она читала каждый компонент отдельным вызовом (11–16 вызовов, 0,7–1,2 ₽), хотя описание `get_subgraph` советует читать запись одним вызовом. Лимит вызовов и финальный шаг не дают этому выйти из-под контроля.
- **Промежуточные фразы попадают в ответ.** Перед вызовом инструментов модель иногда пишет «Сначала посмотрю…»; это часть ответа. Один раз такая фраза была по-английски.
- **Подпись валюты в первые секунды.** Если вопрос задан, пока каталог моделей RouterAI ещё загружается (приложение ждёт его до 20 с), стоимость в ответе считается верно, но без подписи валюты.

# Проверка 19 октября 2026 (вечер)

Модель `deepseek/deepseek-v4.1-flash`, API `https://routerai.ru/api/v1`, ключ и учётные данные IACPaaS из локального `.env` (значения в отчёт не включены). Проверка шла на копии рабочих данных, чтобы не затронуть запущенный экземпляр приложения.

## Автоматические проверки

`pytest`: 60 тестов, все проходят. Среди них:

- агент без принудительного вызова инструмента, финальный ответ при исчерпании шагов, лимит вызовов, обрезанный ответ;
- ошибка провайдера (HTTP 402) посреди хода через настоящий MCP-сервер доходит до пользователя своим текстом, диалог после неё не блокируется;
- живое чтение подграфа с подменённой платформой: путь к вершине, кэш, откат на индекс при недоступности, сдвиге вершины и пути с «/»;
- подсчёт 20 тысяч вершин быстрее 2 с; сжатие старых ходов истории; миграция старой базы диалогов;
- стоимость по прайсу и по сумме провайдера; каталог моделей; описание данных для вкладки «Данные».

## Платформа IACPaaS

- Экспорт фрагмента с `start-target-concept-path=/Сплавы на основе железа/12Х18Н10Т` работает. Вершины, полученные с платформы, совпали с индексом (13 из 13 на глубине 2).
- Один живой запрос занимает 2–6 с, первый — дольше из-за входа.
- `count_graph` от корня справочника: 93 593 вершины за 0,34 с. До исправления на 4 тысячах вершин было 77 с, а от корня подсчёт не завершался.
- Единица «кг/м³» (в имени есть «/») читается из индекса с причиной `PATH_NOT_ADDRESSABLE`.

## Расход

- Окно контекста из каталога RouterAI: 1 048 576 токенов, бюджет истории 1 044 480.
- Вопрос о составе 12Х18Н10Т: 6 вызовов инструментов, около 51 тысячи входных токенов, 0,40 ₽. До облегчения выдачи подграфа было 15 вызовов и 0,73 ₽.
- Простые вопросы без инструментов стоят 0,01–0,05 ₽.
- Стоимость берётся из `usage.cost`, который присылает RouterAI. Она в 3–7 раз выше расчёта по ценам каталога (вход около 5 ₽, выход около 10 ₽ за миллион токенов). Видимо, у провайдера своя тарификация, например учитываются рассуждения модели. В интерфейсе показана фактическая сумма провайдера.

## Как повторить

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m materials_chat
```

Каждый вопрос в чате — платное обращение к RouterAI. Поиск идёт по индексу; актуализировать его можно кнопкой «Обновить из IACPaaS» в разделе «Данные».
