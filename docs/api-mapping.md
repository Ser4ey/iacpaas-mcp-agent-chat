# MCP-инструменты и API IACPaaS

Названия инструментов — интерфейс нашего адаптера. Они не означают наличие одноимённых HTTP endpoints в IACPaaS. Общая логика одинакова для stdio и Streamable HTTP (`materials_chat/service.py`).

## Используемые операции платформы

| Операция | HTTP-запрос | Для чего используется |
|---|---|---|
| Вход | `POST /api/signin` | Получить JWT по логину и паролю (действует 24 часа, обновляется автоматически) |
| Экспорт ресурса | `GET /api/data/export/user-item?path=…&json-type=universal` | Полная загрузка ресурса в локальный индекс |
| Экспорт фрагмента | то же + `start-target-concept-path=/…` и `export-depth=N` | Живое чтение вершины и её подграфа |

- `path` — путь относительно «Мой Фонд», например `Загрузки / Справочник по материалам`.
- `start-target-concept-path` — путь к вершине **внутри ресурса**: имена вершин от корня через `/`, начиная с `/` и без самого корня. Пример: `/Сплавы на основе железа/12Х18Н10Т`. Имя, в котором есть `/`, заключается в тройные кавычки: `/Физические свойства/Плотность вещества/‴кг/м³‴`. Другие варианты платформа отклоняет: «путь должен начинаться с символа 'слеш' (и не включать корневое понятие)».
- `export-depth` — глубина от этой вершины (0 — только она сама). Платформа дополнительно отдаёт цепочку от корня до вершины; адаптер спускается по ней и проверяет, что `id` совпадает с ожидаемым.

Авторизация — `Authorization: Bearer …`. Ответ содержит JSON графа строкой в поле `data`; адаптер разбирает оболочку и проверяет формат. [Официальное описание HTTP API](https://iacpaas.dvo.ru/docs/RemoteCalls/RemoteCalls.html).

## Сопоставление

| MCP tool | Назначение | Что фактически выполняется | `meta.served_from` |
|---|---|---|---|
| `list_inforesources` | Список разрешённых ресурсов | Фильтрация `config/resources.json` и состояние индекса | `configuration` |
| `get_inforesource` | Метаданные ресурса | Экспорт корня (`export-depth=0`): дата изменения, онтология, комментарий; размер графа — из индекса | `iacpaas_live` |
| `search_graph` | Лексический поиск по вершинам | SQLite FTS5 по локальной копии: у платформы нет поиска по тексту | `local_index` |
| `find_materials` | Подбор марок по химическому составу: условия на элементы, класс, сортировка, страницы | Расчёт по таблице состава (`materials_chat/composition.py`), построенной из локального индекса: диапазоны содержания, гарантированное сравнение | `local_index` |
| `get_subgraph` | Вершина и её окрестность до глубины 8 | Путь к вершине берётся из индекса → экспорт фрагмента с платформы → та же постраничная выдача | `iacpaas_live` |
| `count_graph` | Число вершин и дуг | Обход графа в индексе (весь справочник — около 0,3 с) | `local_index` |
| `validate_resource` | Проверка структуры | Локальная проверка формата, онтологии и непустоты | `local_index` |

Когда живое чтение невозможно, `get_subgraph` и `get_inforesource` отвечают из индекса с `served_from: local_index_fallback` и причиной в `meta.live_error`:

| Код | Причина |
|---|---|
| `PLATFORM_UNAVAILABLE`, `PLATFORM_TIMEOUT`, `ACCESS_DENIED`, `PLATFORM_REJECTED` | Ошибка сети, доступа или ответа платформы |
| `PATH_NOT_FOUND` | Путь к вершине не удалось восстановить по индексу (например, индекс обновился во время запроса) |
| `NODE_MOVED` | На платформе по этому пути другая вершина: ресурс изменился после индексации |

Фрагменты больше `LIVE_MAX_NODES` (5000 вершин) читаются из индекса (`meta.live_skipped`). Повторное чтение того же фрагмента в течение минуты берётся из кэша.

`query_graph` из задания реализован как `find_materials`: это поддерживаемый запрос с ограниченными параметрами (условия на состав марок, класс, сортировка, страницы). Произвольный язык графовых запросов не заявляется. Лексический поиск по тексту — `search_graph`. Методы внутреннего Java API IACPaaS внешнему приложению недоступны и не выдаются за HTTP endpoints.

## Результаты и ошибки

Результат содержит полезные данные, источник (`served_from`, `indexed_at` или `fetched_at`) и признаки ограничения выборки (`has_more`, `next_offset`, `truncated`). В подграфе у вершин нет повторяющихся полей: структуру задают дуги `edges`, полный путь указан только у корня. Вершина, часть потомков которой не попала в выдачу (по глубине или странице), помечена полем `children_not_loaded` с их числом.

Следует различать:

- Успешный поиск без совпадений: в выбранном снимке и по данному запросу сведений нет.
- Неизвестный идентификатор или путь: ошибка параметров, а не отсутствие материала.
- Отказ доступа: пользователь не может прочитать ресурс.
- Ошибка сети, таймаут или ошибка формата: данные получить не удалось.
- Достигнут лимит: получена часть результата; нужно сузить запрос или читать следующий фрагмент.

Ошибка передаётся модели как диагностируемый результат инструмента. Агент может исправить аргументы или объяснить проблему, но не должен заменять ошибку вымышленным ответом.

## Что намеренно отсутствует

Импорт, обновление и удаление в API платформы есть, но как инструменты не публикуются: выданный комплект доступен только для чтения. Запуск произвольного сервиса платформы тоже не предоставлен. У модели нет произвольного HTTP-клиента и нет возможности выбрать путь вне разрешённого набора.
