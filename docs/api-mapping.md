# MCP-инструменты и API IACPaaS

Названия инструментов — интерфейс нашего адаптера. Они не означают наличие одноимённых HTTP endpoints в IACPaaS. Общая логика одинакова для stdio и Streamable HTTP.

## Используемые операции платформы

| Операция | HTTP-запрос | Для чего используется |
|---|---|---|
| Вход | `POST /api/signin` | Получить JWT по логину и паролю |
| Экспорт | `GET /api/data/export/user-item` | Прочитать разрешённый ресурс в `universal` |

Экспорт получает `path` относительно «Мой Фонд», например `Загрузки / База свойств материалов`, и `json-type=universal`. Документация также определяет ограничение глубины и начальную вершину. Авторизация — `Authorization: Bearer …`. Ответ платформы может содержать JSON графа как строку в поле `data`; адаптер разбирает оболочку и проверяет результат. [Официальное описание HTTP API](https://iacpaas.dvo.ru/docs/RemoteCalls/RemoteCalls.html).

## Сопоставление

| MCP tool | Назначение | Что фактически выполняется |
|---|---|---|
| `list_inforesources` | Найти разрешённые ресурсы | Фильтрация настроенного списка; это не поиск по всему фонду платформы |
| `get_inforesource` | Метаданные и краткая структура ресурса | При необходимости экспорт; затем чтение метаданных локальной копии |
| `search_graph` | Лексический поиск по вершинам | Поиск в локальном SQLite-индексе JSON, полученного от платформы |
| `get_subgraph` | Ограниченный фрагмент вокруг вершины | Обход нормализованного локального графа по идентификатору и лимитам |
| `count_graph` | Число вершин и связей | Подсчёт в нормализованной копии; не вызов Java API платформы |
| `validate_resource` | Проверка структуры прочитанного ресурса | Локальная проверка JSON и графовой структуры; не импорт и не изменение |

Точные имена аргументов и пределы публикуются самим MCP-сервером в `tools/list`. Идентификаторы ресурсов и вершин нужно получать от инструментов, не придумывать по названию.

`query_graph` из примера задания заменён ограниченным `search_graph`: произвольный язык графовых запросов не заявляется. Методы внутреннего Java API IACPaaS для внешнего Python-приложения напрямую недоступны; они не выдаются за HTTP endpoints.

## Результаты и ошибки

Результат содержит полезные данные, источник и сведения об ограничении выборки. Для поискового попадания важны ресурс, вершина, её путь и краткое содержание. Для подграфа — возвращённые вершины/связи, запрошенная глубина и признак усечения. Время синхронизации показывает актуальность локального снимка.

Следует различать:

- Успешный поиск без совпадений: в выбранном снимке и по данному запросу сведений не найдено.
- Неизвестный идентификатор или путь: ошибка параметров, а не отсутствие материала.
- Отказ доступа: пользователь не может прочитать ресурс.
- Ошибка сети, таймаут или ошибка формата: данные получить не удалось.
- Достигнут лимит: получена часть результата; нужно сузить запрос или читать следующий фрагмент.

Ошибка передаётся как диагностируемый результат инструмента. Агент может исправить аргументы, запросить уточнение или объяснить проблему; он не должен заменять ошибку вымышленным ответом.

## Что намеренно отсутствует

Импорт, обновление и удаление существуют в API платформы, но не публикуются как инструменты: выданный комплект доступен только для чтения. Запуск произвольного сервиса платформы также не предоставлен. У модели нет произвольного HTTP-клиента или возможности выбрать другой путь вне разрешённого набора.

Сервис не обещает поиск в реальном времени на стороне IACPaaS, транзакционную актуальность кэша и самостоятельное получение новых научных выводов. Все ответы должны быть связаны с прочитанными ресурсами.
